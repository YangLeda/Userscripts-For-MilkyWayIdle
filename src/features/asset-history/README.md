# MWITools Asset History

This module is a native MWITools implementation inspired by Everyday Profit
Plus Fixed `2026.01.29.1.2`. The referenced script is MIT licensed and credits
VictoryWinWinWin, PaperCat, SuXingX, and Sunrishe.

MWITools keeps its own structured asset snapshots and does not copy the
standalone script's DOM parsing, global timer, or global hook architecture.
Legacy `kbd_calc_*` data is read only for migration and is left untouched.
