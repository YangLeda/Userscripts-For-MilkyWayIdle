# MWITools Asset History

This module combines MWITools' structured asset snapshots with the interface
and non-cloud workflows adapted from Everyday Profit Pro `26.3.1`. The
referenced script is MIT licensed and credits VictoryWinWinWin, PaperCat,
SuXingX, and ColaCola; the copyright and permission notice is retained in the
asset-center source and generated userscript.

MWITools keeps its own seven-component structured asset snapshots and does not
adopt the standalone script's DOM parsing, cloud synchronization, account
credentials, global timer, or global hook architecture. Legacy `kbd_calc_*`
and `ep_*` data is read only for migration and is left untouched.
